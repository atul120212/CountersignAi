OperateGuard AI is an operations compliance copilot. An analyst uploads a vendor SOW, contract or invoice; Gemini 3.5 Flash on Vertex AI reads the PDF (even scanned pages) and extracts terms with page-cited quotes that code verifies. A Policy Audit agent checks each term against company policy retrieved with Gemini embeddings; a verifier drops any finding without a verbatim snippet retrieved in that run, and code computes risk score and routing. Gemini drafts the ERP entry, Jira tickets and rationale, but nothing executes until a human approves. Firebase Auth signs analysts in (one-click guest access) and Firebase Hosting serves the console. Cloud Firestore holds case state, drafts, a hash-chained tamper-evident audit log, and the live agent trace streamed to the browser with real-time listeners. Cloud Run hosts the FastAPI API, agent pipeline and human approval gate, the only code path that writes to the mock ERP/Jira. Cloud Storage keeps uploads; BigQuery mirrors the audit trail.
